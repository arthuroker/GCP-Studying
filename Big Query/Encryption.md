
*Encryption*

By default, Google-managed encryption is used

Automatically rotated regularly

*CMEK (Customer managed-encryption keys)*

Use CMEK with datasets for more control

Especially useful for compliance/regulation

Use Cloud KMS

Can also be configured at the table-level

*Using CSEK*

BQ does not natively support customer-supplied encryption keys

Therefore, you need to encrypt the data yourself before bringing it to BQ


 *IAM roles to know*
 
 *Big Query Admin* - Full control over BQ
	Can be granted at all kinds of different levels

*Big Query User* - Create data sets and manage jobs
	Can be granted at project and dataset level

*BQ Data Owner* - Manage and share datasets/views
	Granted at project and dataset

*BQ Data Editor* - Create, modify, and delete table data
	Project, dataset, view, and table level

*BQ Data Viewer* - read-only access to tables and views
	Project, dataset, view, and table level

*BQ Job User* - Run jobs and queries
	Only at project level

*BQ Metadata viewer* - access table/dataset metadata
	Any level

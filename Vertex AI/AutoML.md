
*What is it*

No-code solution for the entire model development process

Takes your data and automatically builds, trains, optimizes models through a guided interface

Automatically create features, test algorithms/architectures, tunes hyper parameters, provides evaluation, and easily deploys model endpoints

1) Input data
2) AutoML pipeline (feature engineering, model search, hyper parameter tuning, model training, evaluation and selection)
3) One-click deployment to model registry
4) Deployed to endpoint

*Downsides*

1) Cost
2) Limited customization
3) Data format restrictions

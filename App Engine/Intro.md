
Fully managed Platform as a Service that allows developers to build, deploy, and scale applications without managing the underlying infrastructure

There are configuration files to define app settings

Supports multiple programming languages and frameworks

Essentially builds the container for you at a higher layer of abstraction

*App Engine Setup*

Each project can only host *one* app engine application

App engine apps are regional and cannot be changed

*Configuration*

Uses a YAML file that specifies settings such as runtime, env variables, and scaling paramteres

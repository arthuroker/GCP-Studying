
*Firestore use cases*

1) Product catalogs (real-time inventory)
2) User profiles for mobile apps
3) Game save states
4) ACID/atomic transactions (like transferring funds between accounts)

Any application that needs highly-available, strongly consistent, structured or semi-structured data at scale, with real time sync of data to clients

*Non Firestore use cases*

1) Analytics
2) Extreme scale (ie. 10 million read)

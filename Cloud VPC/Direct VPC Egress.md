
*Before VPC Egress*

By default, serverless services can't reach private resources

The Google Managed Network (for serverless resources) is separate from a Cloud VPC Network

*Direct VPC Egress versus Serverless VPC Access*

Direct - A serverless service is given an IP address within the VPC, no connector needed

Serverless - Outside the VPC, also there is a connector

Similar services, but different

Direct VPC Egress is the increasingly popular option

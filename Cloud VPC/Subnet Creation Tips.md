
*Subnets*

Defined at the regional level

User can specify the IP range using CIDR notation

**2 rules:**

1) Subnet IP range needs to be within the overall range of the VPC
2) Subnet IP ranges cannot overlap with each other


You can expand a subnet's range without deleting it

0.0.0.0/0 is not valid subnet choice, represents the default route for all IP addresses

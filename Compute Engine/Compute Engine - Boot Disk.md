
*Operating System*

Many options - Debian or Ubuntu for most tasks

*Boot Disk Type (Storage on VM)*

Must always be persistent disks

Block storage designed to be durable and persist even if the VM is deleted

Options:

1. Balanced - general workloads
2. Extreme - maximum performance and cost (ie. database or high I/O demands)
3. SSD - higher performance but not the most
4. Standard - most cost effective

*Boot Disk Size*

Default - 10GB

Can be resized, want to consider increasing when utilization reaches 70-80%

Changing size doesn't affect type

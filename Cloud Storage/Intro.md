
*What is it?*

Holds all types of data
	Blob storage
	Go-to solution for unstructured data

GCP version of AWS S3

Containers are called *buckets*

Individual files/items are called *objects*

Can control access to buckets and even specific objects within the bucket

Generally more economical

Versioning and redundancy is available

Storage classes and regions are configurable

*Types of backups Cloud Storage is good for*

1) Archives - long term data sets that don't need frequent access
2) Database backups
3) Media backups - photos and videos
4) Log files
5) Disk snapshots


*gsutil*

CLI tool specifically for Cloud Storage

Can enable parallel composite uploads to maximize the use of available bandwidth

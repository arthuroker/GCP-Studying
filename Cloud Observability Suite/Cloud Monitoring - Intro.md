Definition: Allows you to *collect, analyze, and visualize* metrics from GCP resources
	Can do real time metrics and alerts

Motivation: Tracks the health and performance of applications and infrastructure

Supports custom dashboards


**Types of Cloud Monitoring Metrics**

Built in:

1. Infrastructure (cpu utilization, disk i/o, network traffic, memory usage)
2. Application (response times, error rates, request rates, latency)
3. System (system load, running processes)

Custom examples:

1. User engagement
2. Business transactions
3. Custom operational/health

External:

1. Multi-cloud
2. On-prem applications
3. On-prem monitoring tools

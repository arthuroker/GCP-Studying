Definition: Allows you to *store, search, and analyze* log data and events from GCP resources and applications. Integrated with Cloud Monitoring

**Log Types**

Platform logs - originate from GCP services themselves

Application logs- originate from code running on GCP

Audit logs - logs activities that have implications for security and compliance


Logs are kept by default for *30 days*, but this can be changed
	Some industries require that you keep logs for longer, however keeping a lot of logs or for a long time require increased storage usage

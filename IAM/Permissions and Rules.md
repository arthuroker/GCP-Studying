
**Roles**: collections of permissions

**3 Roles Types**:

1. Basic - broad permissions at the project level
2. Predefined  - defined by GCP, tailored for common job functions
3. Custom - managed by users any combinations of permissions

**Role Name Formats**

1. Descriptive role name
	Used in documentation or conversation to make it easier to understand

2. Technical role name
	Technical role name used in GCP or gcloud CLI. follows {service}.{rolename} format

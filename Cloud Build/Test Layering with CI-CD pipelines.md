
*The testing progression*

1) Cloud Build (unit tests - fast, individual functions and components)
2) Development (integration and load tests - do the components work together and can system handle expected traffic?)
3) Staging (core functionality tests - can users perform the basic functions of the app?)
4) Production (user traffic and feedback - are business requirements being met?)

From 1 to 4

Cheaper and faster to Slow and more expensive
